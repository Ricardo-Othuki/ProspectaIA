Retomada em 2026-10-01. Objetivo: encontrar grupos publicos na internet onde possam aparecer pedidos reais por sites, automacao, agentes de IA, trafego pago, SEO e SaaS sob medida.

## Criterio de uso

- Entrar apenas em grupos cuja regra permita participacao/observacao sem abordagem invasiva.
- Nao disparar oferta automatica no grupo.
- Usar como fonte de escuta: detectar pedidos reais, depois abordar no privado de forma humana e contextual.
- Priorizar grupos com donos de negocios, lojas, empreendedores, automacao, IA aplicada e marketing digital.
- Baixar prioridade para grupos de "renda extra" muito genericos, afiliados ou spam.

## Automacao no navegador

Foi criado um comando local para reduzir o trabalho repetitivo de abrir links:

```bash
npm run grupos:entrar -- --limite 2
```

Para testar exatamente os 2 grupos novos:

```bash
npm run grupos:entrar -- --url https://gruposwhats.app/group/872980 --url https://gruposwhats.app/group/868359
```

O comando abre os links em fila. Por padrao, usa o Firefox real, porque o Turnstile pode recusar Chromium controlado por Puppeteer. Ele pausa entre links para o usuario resolver Turnstile e confirmar a entrada no WhatsApp.

Se for preciso testar o modo antigo com Chromium automatizado:

```bash
npm run grupos:entrar -- --navegador puppeteer --limite 2
```
